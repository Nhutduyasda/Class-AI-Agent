# Marketing Video 01 — pre-publish QA and acceptance

## Editorial gates — all require explicit review
- [ ] Cold viewer knows within 3 seconds this is for a person *mất gốc tiếng Anh* who has ChatGPT but no study plan.
- [ ] Clear logical progression of HOOK → PROBLEM → SOLUTION → DEMO → BENEFIT → CTA; narration is the approved script in exact order and wording.
- [ ] Comprehensible even if the viewer has not seen the creator, English Journey or Lesson 15 before.
- [ ] The main point is structured learning with review of mistakes; not a random diary about writing a supermarket sentence.
- [ ] Correct factual lesson demo: original unchanged, corrected sentence unchanged, spellings and conjunction actually highlighted.
- [ ] The video does NOT imply automatic persistent cross-chat syncing, official ChatGPT partnership, achieved TOEIC 790, guaranteed results or fake user testimonials.
- [ ] Last 3–7 seconds contain visible CTA `Bình luận BẮT ĐẦU`; do not promise automated DM fulfillment.

## Audio & rights
- [ ] Real expressive Vietnamese voice track, appropriate pronunciation of Reading/Vocabulary/ChatGPT and English words, checked by listening (not by ASR alone).
- [ ] Real instrumental music track, appropriate for awareness marketing, audible but never masking narration.
- [ ] Music either original demonstrably project-generated or licensed for intended marketing/commercial usage, with source/license info.
- [ ] Clear fades, no click, no severe clipping; voice/music levels documented; SFX only meaningful.
- [ ] Word/subtitle alignment from actual audio not invented durations.

## Visual / export
- [ ] Strong text in first frame; no intro logo/fade before hook.
- [ ] Visuals provide useful contrast: messy inputs → structured journey → live correction → Error Log → CTA.
- [ ] Readable on a real phone; keep key text out of platform overlays and do not display >~2 lines of captions at once.
- [ ] 1080×1920, 30fps, MP4 H.264, AAC mixed audio, genuine output exists and has been inspected.
- [ ] Proof frames: hook, problem, solution, before/after demo, benefit, CTA. Full playback listened to end.
- [ ] QA report includes runtime, assets provenance, voice provider and human reviewer findings.
- [ ] User approves final before any TikTok posting.

If video renders but content fails, status MUST be **NOT APPROVED**. Do not merge automatically.
