Machine-readable JSON Schema exports are in `schemas/auto-factory/`; example identity, profiles and briefs are in `fixtures/auto-factory/`. These snapshots are generated examples; TypeScript is the schema/fixture source of truth.

Presenter `minh-main` carries the requested identity traits, five wardrobes, eight expressions and eight gestures. Asset status is TEXT_REFERENCE_ONLY. The common visibility policy defaults lessons to VOICE_ONLY, small objects to HANDS_ONLY, art to NO_PRESENTER and fashion to HALF_BODY; an explicit allowed override wins. Invalid combinations fail. Identity binding stays in the plan even when no body/face is shown, but does not imply a visual asset exists.

Four voice metadata profiles are implemented. Vietnamese spans route to Nam Minh; standalone English examples route to Andrew. Unsupported expressive style, rate/pitch override or clone reference is rejected. No voice audition, synthesis transport, credential inspection or narrator cloning exists. Metadata does not certify emotional speech or Azure capability.

Product fixtures cover Shopee phone case, TikTok Shop fashion and art planning. Only MANUAL_PROVIDED_EVIDENCE is accepted; supported canonical HTTPS domains are explicit and redirects/shorteners are unsupported. URLs are validated, never fetched. Attribute/claim values must match field evidence and fresh timestamps; exact prices need a matching price field within 24 hours. Missing facts, new unsupported script text, fake personal testing, unknown mode, unsafe URL or stale evidence stops planning. Fixture facts are fictional; contract acceptance is not independent verification of a seller or evidence authenticity. Actual product use needs owner/source verification in later gates.

The ledger is SIMULATION_ONLY. Each fixture scenario has an independent zero-charge ledger so three samples on one date do not represent three scheduled productions. The reusable reserve function enforces one date slot, USD 0.08 per run and USD 8 aggregate including opening liability. USD 2 reserve is inaccessible. Local JSON checkpoints are not a durable multi-runner paid ledger; no Gate 2 Git journal/protection implementation is included.
