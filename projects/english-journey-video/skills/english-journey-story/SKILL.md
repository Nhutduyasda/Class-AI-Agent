# English Journey Story

## Input
Use a brief from `briefs/`. Respect exact ORIGINAL and REVISED text and the project progress. Do not guess private background facts.

## Method
1. State ONE audience pain: "I make this English writing mistake."
2. Hook in the first 1–3 seconds without guaranteeing performance.
3. Show the original sentence with "BEFORE" label.
4. Explain at most **two** high-signal error categories in plain Vietnamese.
5. Show the revised sentence with "AFTER" label; give adequate on-screen reading time.
6. End with a grounded payoff: why repeating the correction helps practice; avoid a forceful sales pitch.
7. Do not invent educational test results, claims of fluency, testimonials, or AI responses.

## Safe storytelling
- Use the brief as an authentic example shared for this project.
- If a screenshot is not supplied, use honest text cards; never fake a real chat UI.
- Redact names/identifiers and any information unrelated to the teaching point.
- Verify all Vietnamese diacritics, English spelling, and punctuation.
- Clearly distinguish user-original text from corrected text.
- Speak in first-person only where it faithfully represents the learner's experience.

## Done when
Storyboard can be read on a 6-inch phone, teaches one useful lesson, and has approved exact text from the brief.
